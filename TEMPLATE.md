# Template provenance

This plugin started from the official
[asdf plugin template](https://github.com/asdf-vm/asdf-plugin-template) at
commit 8ee7a1f9d7eaa2658355df1e9dc9f646cdeab615.

The generated shell code and repository files were adapted for the prebuilt
SecretSpec release archives. The template setup script was not run because it
resets the main branch and creates a generated commit.
